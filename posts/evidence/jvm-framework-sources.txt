## LangGraph4j Spring AI agent executor  https://github.com/langgraph4j/langgraph4j/blob/main/spring-ai/spring-ai-agent/README.md
"`langgraph4j-springai-agentexecutor` provides ReAct-style agents built on LangGraph4j and Spring AI `ChatModel`. Use it when you want a ready-to-run agent loop with tool callbacks, streaming output, approvals, or sub-agents instead of wiring every node manually."
(It offers `AgentExecutor`, a compact ReAct graph with agent -> action -> agent execution, and `AgentExecutorEx`, with explicit tool-dispatch nodes, approval gates and richer orchestration.)
